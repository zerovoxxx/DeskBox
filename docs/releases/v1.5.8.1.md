# DeskBox 1.5.8.1

This fork integrates upstream `main` through `bbb9e697`, including the official 1.5.8 release and the subsequent callback-isolation and file context-menu changes merged on 2026-10-16.

## Integration

- Keep the owned tray menu window and HWND tool-window styles used during Windows logon. Menu opening now runs after the native callback returns, retaining upstream cursor capture, reentry suppression, startup retries, and native-menu fallback.
- Keep persisted shortcut icon resource recovery, extensionless ICO decoding, and the fourth hydration retry. Retain upstream stacked-member icon preservation and transient-failure recovery without clearing decoded icons.
- Integrate upstream startup storm protection, shell-integrity handling, updater restart fixes, drag-and-drop callback isolation, and the revised file context menu.
- Keep the fork's commit identity enforcement, Windows UNC build-script fixes, and framework-dependent installer policy.
- Preserve the upstream SDK pin (`10.0.402`) and dependency lock files. The fork version is `1.5.8.1` across the application, package manifest, and both installer definitions.

## Validation

- Locked-mode restore succeeded with an official .NET SDK 10.0.402 archive verified against Microsoft's SHA-512 release metadata. NuGet vulnerability checks reported no known vulnerable packages.
- Full x64 suite: 5,575 passed and 1 failed out of 5,576 executed tests, with no skipped or aborted tests. `AotAudit_RejectsArm64BeforeResolvingToolsOrTouchingArtifacts` failed because Windows antivirus blocked `publish-aot-audit.ps1` before its architecture guard could execute (`ScriptContainedMaliciousContent`); the same block was reproduced independently.
- The standard non-platform Debug build succeeded with zero errors. Its canonical `DeskBox.dll` was freshly written after the build started and reports version `1.5.8.1`. Existing upstream compiler warnings remain.
- Building through `\\wsl.localhost\Ubuntu` avoids the MSIX PRI expansion tool's URI parsing failure on the equivalent `\\wsl$\Ubuntu` hostname.
- Exactly one DeskBox process was running after restart, from `src/DeskBox/bin/Debug/net10.0-windows10.0.22621.0/DeskBox.exe`. Its startup pipeline completed 40 steps with zero failed or degraded steps.
- All nine existing widget identities and the existing group identity were preserved. Settings changed only in `lastUpdateCheckAt`; the scheduled startup action still points to the installed application with its existing arguments. Actual Windows reboot/logon was not tested.
